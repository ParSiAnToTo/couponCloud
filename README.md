## 프로젝트 소개
쿠폰 클라우드수많은 사용자에게 원활한 쇼핑 경험을 제공하며, 다양한 쿠폰 혜택을 통해 고객 만족도를 높이는 대규모 이커머스 플랫폼입니다. 빠른 상품 탐색, 주문 처리, 쿠폰 관리로 고객 친화적인 쇼핑을 지원합니다.

## 성능 최적화 및 트러블 슈팅

### 성능 최적화
- MSA 도입 : 모노리스 구조에서 서비스 확장성을 위해 마이크로 서비스 아키텍처를 도입했습니다.
- API Gateway 및 Eureka server 도입 : 클라이언트의 요청을 중앙집중화하며, 서비스 확장성을 높이기 위하여 도입
- [추가 예정] gRPC 기반 통신과 kafka 도입
  - REST기반 DB 통신, gRPC 기반 DB 통신, gRPC 기반 메시지 큐잉 성능 테스트 진행 예정
  - 병목 구간을 조사하여 스케일아웃에 대한 고려 필요함
  - 테스트 버전 별 그래프를 통한 시각화 및 정량화 데이터 추가 작성
- 상품 조회 캐시 : 상품 데이터를 Redis에 동기화하여 조회 성능 향상

### 트러블슈팅

- 개인정보 암호화 시 복호화 불가 : 양방향 암호화 알고리즘을 적용하여 해결, 암호키 패턴 고정 시 해석될 수 있는 부분을 방지하기 위해 Initialization Vertor 적용하여 첫 블록의 무작위 암호화 적용
